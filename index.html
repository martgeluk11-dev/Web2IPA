    How do I get a GitHub token?

    Create a fine-grained personal access token, select only the martgeluk11-dev/Web2IPA repository, and grant Actions: Read and write permission. Set an expiry, create it, then paste it above. The token stays in this page's memory and is cleared when the build ends.

    Important: the generated IPA is unsigned. It cannot be installed normally until signed with a valid Apple signing identity. Web2IPA wraps your website; it does not convert it into native Swift code.
