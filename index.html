How do I get a GitHub token?

Create a fine-grained personal access token, select only the martgeluk11-dev/Web2IPA repository, and grant Actions: Read and write permission. Set an expiry, create it, then paste it above. Never share your token with anyone.

Important: the generated IPA is unsigned. It cannot be installed normally until it is signed with a valid Apple signing identity. Web2IPA wraps your website; it does not convert it into native Swift code.
